### Remarks

Each combinator comes in two forms: one takes an ordinary lambda, the other a lambda that returns a
[System\.Threading\.Tasks\.Task&lt;&gt;](https://learn.microsoft.com/en-us/dotnet/api/system.threading.tasks.task-1 'System\.Threading\.Tasks\.Task\`1'). An `async` lambda always binds to the second form. A lambda that merely returns
a task, such as `x => Task.FromResult(x)`, also binds to the second form, because it is the more specific
overload.

`MatchAsync` takes either two ordinary lambdas or two task-returning lambdas. Mixing one of each does not
            compile (the compiler reports a misleading conversion error on the ordinary lambda); make both lambdas the same kind,
            for example by wrapping the plain result in `Task.FromResult`.

All awaits use `ConfigureAwait(false)`. An exception thrown by the source task or by a lambda is not caught;
it faults the returned task. A [null](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/null 'https://docs\.microsoft\.com/en\-us/dotnet/csharp/language\-reference/keywords/null') source task counts as a failure with code
`result.null_task`, and so does a [null](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/null 'https://docs\.microsoft\.com/en\-us/dotnet/csharp/language\-reference/keywords/null') task returned by a lambda. A [null](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/null 'https://docs\.microsoft\.com/en\-us/dotnet/csharp/language\-reference/keywords/null')
delegate behaves as it does on [Result&lt;T&gt;](../Result_T_/index.md 'StandSure\.Functional\.Result\<T\>'): `result.null_delegate` failure, or
`default(TOut)` from `MatchAsync`, which also records a `result.null_delegate` failure in telemetry.
`MapErrorAsync` and `TapErrorAsync` keep the original failure when their delegate, or the task it
returns, is [null](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/null 'https://docs\.microsoft\.com/en\-us/dotnet/csharp/language\-reference/keywords/null'), and record the problem in telemetry only (as `MapError` and `TapError` do). `default(Result<T>)` flows as the
[Uninitialized](../Error/Uninitialized.md 'StandSure\.Functional\.Error\.Uninitialized') failure.
