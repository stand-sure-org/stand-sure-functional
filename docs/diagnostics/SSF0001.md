# SSF0001: use `Unit.Value`

`Unit.Default` is a deprecated alias of `Unit.Value`. Both give the same value: `Unit` has only one.

```csharp
return Result.Success(Unit.Default); // SSF0001
return Result.Success(Unit.Value);   // fix
return Result.Success();             // shorter: Result<Unit>
```

## Why the alias exists

Other libraries name this value `Unit.Default`, so people and code-writing models guess that name. Without the alias, the guess fails with CS0117 ("'Unit' does not contain a definition for 'Default'"), which doesn't say what to use instead. With the alias, the code compiles and this warning names the correct member. The alias is permanent and hidden from IntelliSense.

## Suppressing

If you have `TreatWarningsAsErrors` on, the warning breaks the build. The fix above is one word. To accept the alias instead, suppress only this ID:

```xml
<NoWarn>$(NoWarn);SSF0001</NoWarn>
```
